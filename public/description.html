This API provides authoritative U.S. polygon-based geographic lookups and metadata derived from curated GIS boundary datasets.

Endpoints support querying by attribute (e.g., state code, MLRA symbol) or by geographic location (latitude/longitude), returning the polygon that covers a given point using boundary-inclusive spatial logic.

The API is designed for lightweight, high-performance spatial lookups suitable for dashboards, mapping applications, and downstream geospatial models.
