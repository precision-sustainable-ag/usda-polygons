Returns USDA plant hardiness zone metadata and geometry based on a geographic point.

The zone identifies a range of average annual extreme minimum temperatures.

Parameters

ParameterTypeRequirementDescription
latnumberRequiredLatitude in decimal degrees.
lonnumberRequiredLongitude in decimal degrees.
polygonbooleanOptional; default falseInclude WKT polygon geometry when true.

Examples

  • $ANCHOR[/hardiness?lat=35.77&lon=-105.54]
  • $ANCHOR[/hardiness?lat=35.77&lon=-105.54&polygon=true]

Returns USDA plant hardiness zones for a state, optionally clipped to an ecoregion.

State-only data comes from precomputed state-zone geometry; state-plus-ecoregion data from precomputed state/ecoregion-zone geometry. The endpoint supports simplified WKT polygons.

Parameters

ParameterTypeRequirementDescription
statestringRequiredState postal abbreviation.
ecoregionstringOptionalRestrict results to this ecoregion code within the requested state.
polygonbooleanOptional; default falseInclude WKT polygon geometry when true.
simplifynumberOptional; default 0Simplification tolerance in meters; 0 returns unsimplified geometry.

Examples

  • $ANCHOR[/hardinessbystate?state=GA]
  • $ANCHOR[/hardinessbystate?state=GA&polygon=true]
  • $ANCHOR[/hardinessbystate?state=OR&ecoregion=7&polygon=true&simplify=100]

Performance: Spatial intersections are precomputed in derived tables; polygon simplification is performed when geometry is requested.

Returns a list of Ecoregions for a given state name or code.

Only Ecoregions overlapping the state by at least 1 km² are included. Polygons are clipped to the state's boundaries.

The optional simplify parameter reduces polygon detail using a tolerance specified in meters. The default is 0 (no simplification).

Parameters

ParameterTypeRequirementDescription
statestringRequiredTwo-letter state code or full state name.
polygonbooleanOptional; default falseInclude WKT polygon geometry when true.
simplifynumberOptional; default 0Simplification tolerance in meters; 0 returns unsimplified geometry.

Examples

  • $ANCHOR[/ecoregionsbystate?state=FL]
  • $ANCHOR[/ecoregionsbystate?state=Florida]
  • $ANCHOR[/ecoregionsbystate?state=FL&polygon=true]
  • $ANCHOR[/ecoregionsbystate?state=FL&polygon=true&simplify=100]

Performance: Spatial intersections are precomputed in derived tables; polygon simplification is performed when geometry is requested.
