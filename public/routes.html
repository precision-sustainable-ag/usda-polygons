Returns U.S. county metadata and geometry based on a geographic point.

Examples

  • $ANCHOR[/county?lat=34.77&lon=-105.54]
  • $ANCHOR[/county?lat=34.77&lon=-105.54&polygon=true]

Returns U.S. ecoregion metadata and geometry based on a geographic point.

Examples

  • $ANCHOR[/ecoregion?lat=34.77&lon=-105.54]
  • $ANCHOR[/ecoregion?lat=34.77&lon=-105.54&polygon=true]

Returns USDA plant hardiness zone metadata and geometry based on a geographic point.

Examples

  • $ANCHOR[/hardiness?lat=34.77&lon=-105.54]
  • $ANCHOR[/hardiness?lat=34.77&lon=-105.54&polygon=true]

Returns Land Resource Unit (LRU) metadata and geometry based on a geographic point.

Note that LRUs are available for New Mexico only.

Examples

  • $ANCHOR[/lru?lat=34.77&lon=-105.54]
  • $ANCHOR[/lru?lat=34.77&lon=-105.54&polygon=true]

Returns Major Land Resource Area (MLRA) metadata and geometry based on a geographic point or MLRA symbol.

Examples

  • $ANCHOR[/mlra?lat=34.77&lon=-105.54]
  • $ANCHOR[/mlra?lat=34.77&lon=-105.54&polygon=true]
  • $ANCHOR[/mlra?mlra=48A]
  • $ANCHOR[/mlra?mlra=48A&polygon=true]

Returns U.S. state metadata and geometry based on a geographic point or state name or code.

Examples

  • $ANCHOR[/state?lat=34.77&lon=-105.54]
  • $ANCHOR[/state?lat=34.77&lon=-105.54&polygon=true]
  • $ANCHOR[/state?state=GA]
  • $ANCHOR[/state?state=Georgia]
  • $ANCHOR[/state?state=GA&polygon=true]

Returns watershed metadata and geometry based on a geographic point.

Examples

  • $ANCHOR[/watershed?lat=34.77&lon=-105.54]
  • $ANCHOR[/watershed?lat=34.77&lon=-105.54&polygon=true]

Returns a combined set of polygon lookups for a geographic point, including county, state, MLRA, LRU, watershed (HUC), USDA hardiness zone, and ecoregion.

Ecoregion is returned as the covering ecoregion when available; otherwise the nearest ecoregion is returned.

Examples

  • $ANCHOR[/info?lat=34.77&lon=-105.54]

Returns a list of U.S. counties for a given state.

The state may be specified using a two-letter state code.

Examples

  • $ANCHOR[/counties?state=GA]

Returns a list of U.S. states with basic metadata and geographic context.

Each record includes the state name, state code, FIPS code, capital city and its coordinates, a bounding box, and the centroid of the state geometry.

Examples

  • $ANCHOR[/states]

Returns a list of valid Major Land Resource Area (MLRA) symbols.

This endpoint provides the set of MLRA identifiers available for lookup in the MLRA dataset.

Examples

  • $ANCHOR[/validmlra]

Returns USDA Crop Sequence Boundaries (CSB) metadata for the land cover history at a geographic point.

Note that CSB coverage is limited to areas classified as cropland in at least one year; locations outside mapped cropland will return no result.

Examples

  • $ANCHOR[/csb?lat=35.5&lon=-90.93]
